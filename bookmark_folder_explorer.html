Upload a Netscape-format bookmarks HTML file and find any folder inside it.
Choose an exported bookmarks HTML file to begin.
Opening multiple bookmarks: browsers may block multiple tabs/windows unless they are opened as a direct result of your click. If Chrome blocks them, use the fallback below: each batch is opened through one reusable window, where you can close the whole batch at once.
Folder matching is case-insensitive. Only the direct bookmarks inside a matched folder are opened by its Open all button; subfolders are displayed but their bookmarks are not included in that button.
